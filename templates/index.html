Important Information

TrustLens identifies potential warning indicators using predefined checks. Results do not guarantee that a website is safe or malicious. Always verify unfamiliar links before sharing personal information.

How TrustLens Works

TrustLens examines URL structures using six predefined checks to identify potential warning indicators.

  • HTTPS connection detection
  • IP address identification
  • Unusually long URL detection
  • Username information detection
  • Recognized URL shortener detection
  • Uncommon domain ending detection

Understanding the Results

A warning indicator does not automatically mean a website is malicious. It simply identifies something that may deserve closer attention.

Likewise, finding no warning indicators does not guarantee that a website is safe.

Current Limitations

TrustLens currently uses predefined Python rules. It does not connect to live threat intelligence databases, scan website content, or verify a website's reputation.
